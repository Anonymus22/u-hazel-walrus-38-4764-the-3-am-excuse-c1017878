# The 3 AM Excuse

One line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM: a device that remembers every previous 3 AM "urgent" trade and knows exactly how the morning after goes.

`main.ts` writes the entry line to `/output/entry.txt`.
